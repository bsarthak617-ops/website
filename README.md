# Oilteq Industries — Industrial Energy & Fuel Supply Platform

A modern, high-performance B2B digital platform engineered for **Oilteq Industries**, an established industrial energy manufacturer, importer, processor, and bulk fuel supplier.

---

## 🏭 Overview

Oilteq Industries delivers specialized industrial fuel solutions across India and international markets, specializing in high-efficiency substitutes for Furnace Oil (FO) and Light Diesel Oil (LDO), direct import processing, and bulk supply chains.

This web platform is designed with an editorial, engineering-led aesthetic tailored to enterprise procurement heads, plant engineers, and supply chain directors.

---

## ⚡ Core Capabilities & Features

- **Technical Fuel Specification Engine**: Side-by-side comparative parameter tables (Gross Calorific Value, Kinematic Viscosity, Flash Point, Ash Content, Moisture Content) with ASTM test standards.
- **Enterprise RFQ & Procurement Portal**: Streamlined inquiry workflow supporting tanker-load volume specifications, plant destination routing, delivery frequency selection, and automated inquiry referencing (`RFQ-XXXXX`).
- **Interactive Infrastructure & Supply Chain Explorer**: Interactive visualization covering manufacturing facilities (Jharsuguda, Odisha), dedicated quality assurance laboratories, port import terminals (Kolkata & Haldia), and GPS-tracked insulated tanker fleet logistics.
- **Dynamic Industry Applications**: Technical suitability breakdown for steel plants, aluminium smelters, rolling mills, forging units, boiler operations, and road construction.
- **Bilingual Dark / Industrial Sand Theme**: Precision-tuned color palette featuring Industrial Dark Navy/Slate (`#0B0F19`), Warm Engineering Sand (`#EEECE3`), Safety Orange accents (`#F25C05`), and High-Visibility Cyan (`#00D4B2`).
- **Smooth Micro-Interactions**: Built using Framer Motion for buttery-smooth tab transitions, interactive hotspots, and hover-triggered technical deep dives.

## 🛠 Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)

- **Motion & Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Fonts**: Inter & JetBrains Mono (Technical / Engineering typography)

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation

```bash
# Clone repository
git clone https://github.com/namyavenkatraman-design/oilteq.git

# Navigate into project directory
cd oilteq

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
# Create optimized production bundle
npm run build

# Preview production build locally
npm run preview
```
